# Todo List App

A simple browser-based todo application built with plain HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as complete or active
- Delete individual tasks
- Filter tasks by all, active, or completed
- Clear completed tasks
- Tasks persist in the browser using localStorage

## Project Structure

- `index.html` — app layout
- `style.css` — styling and responsive design
- `script.js` — todo logic and browser storage

## How to Run

1. Open the project folder in your browser, or
2. Start a local web server in the project directory:

```bash
python -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```

## Notes

This project is intentionally lightweight and does not require any dependencies or build tools.
